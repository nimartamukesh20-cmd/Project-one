EVIDENCE FILE 01

Monogrammed Handkerchief

Location Found

A white handkerchief was recovered beneath a chair in Richard Vale's private suite.

Description

The handkerchief has the initials "E.V." embroidered in one corner.

Investigator's Note

The handkerchief suggests Evelyn Vale visited the suite, but it does not establish when she was there.

EVIDENCE FILE 02

Burned Financial Document

Location Found

Partially burned company financial records were recovered from the fireplace in Richard Vale's suite.

Description

The surviving pages show several unauthorized transfers involving millions of dollars. Adrian Cole's name appears on the records connected to these transactions.

Investigator's Note

Richard may have discovered that money was being taken from his company. The damaged documents raise questions about Adrian's involvement.

EVIDENCE FILE 03

Access Card Log

Security Record

Electronic security logs show that Daniel Mercer's employee access card unlocked Richard Vale's suite at exactly 11:04 PM.

Observation

The security system recorded the card number, but it could not identify who was physically carrying the card.

Was Daniel the person who entered the suite, or could someone else have used his card?

EVIDENCE FILE 04

Security Jacket

Location Found

A ship security jacket was discovered on the floor near the entrance to Richard Vale's private suite.

Description

The jacket was identified as belonging to Marcus Reed, a member of the ship's security team.

Investigator's Note

The jacket places Marcus under suspicion, but there is no evidence confirming that he was wearing it near the time of the murder.

EVIDENCE FILE 06

Meeting Message

Description

Investigators recovered a message from Richard Vale's phone arranging a private meeting in his suite at 10:45 PM.

Message Text

"Meet me in my suite at 10:45 PM. We need to settle this before we reach port."

Investigator's Note

The message was addressed to Adrian Cole. Investigators are examining what Richard wanted to discuss with him.

EVIDENCE FILE 07

Witness Statement

Statement

A lounge attendant reported witnessing a heated argument between two men on the evening of Richard Vale's murder.

Witness Identification

The attendant identified the men as Adrian Cole and Daniel Mercer. Their disagreement appeared serious, and both were visibly angry.

Investigators have not yet established what caused the argument.

EVIDENCE FILE 08

Secret Messages

Description

Recovered deleted messages reveal that Evelyn Vale and Adrian Cole were secretly involved in a romantic relationship.

Recovered Message

"Richard can't know about us. Once this trip is over, everything will change."

Investigator's Note

The messages reveal a possible motive for both Evelyn and Adrian. However, the affair alone does not establish who murdered Richard.
