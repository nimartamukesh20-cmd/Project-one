EVIDENCE FILE 01

Monogrammed Handkerchief

Location Found

Recovered from Richard Vale's private suite, folded beneath a chair beside the window.

Description

A white embroidered handkerchief with the initials "E.V."

Investigator's Note

The owner clearly entered through the suite at some point, but this does not determine when the item was left behind.

Burned Financial Document

Description

Many half-burned accounting records were recovered from the suite fireplace.

Observation

Although damaged, the remaining pages refer unusual company transfers worth millions of dollars.

Someone absolutely wanted these documents gone before the investigators arrived.

EVIDENCE FILE 03

Access Card Log

Security Record

Electronic logs show Daniel Mercer's employee access card unlocked Richard Vale's suite at exactly 11:04PM.

Observation

No additional entries were recorded until security discovered the body.

The access card links Daniel to the suite - but not necessarily the murder.

EVIDENCE FILE 04

Security Jacket

Location Found

A folded, ship security jacket was discovered inside a maintenance closet near Richard Vale's suite.

Description

The jacket belongs to the ship's security department and is assigned to Marcus Reed.

Investigator's Note

Its location raises suspicion, but there is no proof th jacket was worn during the murder.
